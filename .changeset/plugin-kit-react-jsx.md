Require `"jsx": "react-jsx"` instead of `"jsx": "preserve"` in `verify-package`'s tsconfig check and in the `tsconfig.settings.json` generated by `init`. With `@sanity/pkg-utils` v12 the tsconfig `jsx` option controls the emitted JavaScript, so `preserve` left raw JSX in `dist/*.js` that Studio could not load. Existing plugins should update `compilerOptions.jsx` to `"react-jsx"`.
