Run Mux Robots on the v1 API. New jobs and directive runs use v1, and jobs and directive runs Robots v0 created, before the upgrade or from v0 directives attached to uploads, are still read on v0, so their outputs keep reaching the video document. **Analyze structure** replaces **Find scenes**, which v1 doesn't have: one run returns a title, summary, tags, chapters, scenes and key moments, also on audio-only videos, and **Apply summary** uses the newest of it and Summarize. **Translate captions** and **Translate audio** can name the new track. **Captions to read** lists the video's own caption languages, since v1 reads only an exact language match. **Moderate** also moderates what is said in the captions by default, as Robots v1 does, and can be limited to the sampled frames. **Edit captions** replaces the original track and keeps its name by default, or keeps the original under a new name for the edited track. Key moment lengths are set in seconds. Directives made with Robots v0 can't be run from the Studio, and the Robots panel and upload dialog say which configured ones to replace with a v1 copy. Requires the Mux proxy with Robots v1 routes.
